# 🚆 Railway Coach Health Monitoring System

This project is a simple and interactive dashboard developed using Streamlit to monitor the health of railway coaches. It analyzes key parameters such as temperature, vibration, and door status to determine whether a coach is in a healthy condition or requires maintenance.

## 📌 Features
- Displays coach data in a structured table  
- Detects faults based on predefined conditions  
- Classifies coach status as "Healthy" or "Maintenance Required"  
- Provides interactive input controls for real-time checking  
- Visualizes data using line and bar charts  

## 🛠️ Tech Stack
Python | Pandas | Streamlit  

## ▶️ How to Run
1. Install required libraries:
   pip install streamlit pandas  

2. Run the application:
   python -m streamlit run app.py  

3. Open in browser:
   http://localhost:8501  

## 🎯 Use Case
This system can help in railway maintenance by identifying potential issues early and supporting better decision-making for preventive maintenance.
